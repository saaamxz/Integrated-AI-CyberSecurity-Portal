# Integrated AI & Cyber Security Portal 

منصة تعليمية متكاملة تجمع بين تطبيقات الذكاء الاصطناعي وتحديات الأمن السيبراني في لوحة تحكم (Dashboard) واحدة.

## نبذة عن المشروع
تم دمج مشروعين مختلفين في نظام واحد لتقديم واجهة تحكم شاملة (Portal) تتيح للمستخدم التنقل بين:
1. **AI Salary Predictor:** نموذج ذكاء اصطناعي لتوقع المرتبات بناءً على البيانات.
2. **SQLi Defense Simulator:** مختبر أمني تفاعلي لشرح ثغرات الحقن (SQL Injection) وكيفية الحماية منها.

## المميزات الرئيسية
- **Dashboard مركزية:** تنقل سلس بين الموديلات الأمنية والذكاء الاصطناعي.
- **تطبيق أمني (Cyber Security):** محاكاة واقعية لثغرات الـ SQLi مع وجود وضعين (Secure vs Unsecure).
- **محرك ذكاء اصطناعي:** حساب التوقعات المالية باستخدام معادلات الانحدار.
- **تصميم تفاعلي:** واجهة مستخدم حديثة ومبسطة.

## التقنيات المستخدمة
- **Backend:** Python (Flask Framework).
- **Database:** SQLite.
- **Frontend:** HTML5, CSS3, Bootstrap 5.
- **Security Concepts:** Input Validation, Parameterized Queries.
